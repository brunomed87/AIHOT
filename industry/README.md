# Pacote do setor

Configurações específicas ficam aqui. Siga [personalização](../docs/customize.md).

| Arquivo | Conteúdo |
|---|---|
| site.ts | Nome, setor, textos iniciais, apresentação e registro ICP opcional |
| taxonomy.ts | Categorias, marcadores, instituições e vocabulário de identidade |
| topics.json | Catálogo de temas de /topics |
| sources.json | Fontes importadas na primeira execução |
| prompts/ | Pré-seleção, pontuação, redação, estrutura, agrupamento, síntese, relatórios e tradução |
| selection.ts | Limites de seleção |
| features.ts | Ranking de modelos e monitor Codex |
| brand/ | Ícones, marca e títulos dos relatórios |
| pages/ | Modelos de termos e privacidade, a revisar antes de publicar um site |
| changelog.json | Histórico de atualizações |
| gold.example.jsonl | Exemplos anotados para avaliação |
