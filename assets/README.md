# Recursos estáticos

Arquivos servidos diretamente pelo site. Preserve os documentos de direitos e licenças que os acompanham.

| Diretório | Conteúdo | Observação |
|---|---|---|
| og-fonts/ | Noto Sans SC 400/700, SIL OFL 1.1 | Apenas imagens geradas no servidor; interface usa fontes do sistema sem requisições externas |
| model-providers/ | Marcas de fornecedores e famílias de modelos | Identificação no ranking; direitos dos titulares, conforme NOTICE |
| leaderboard-sources/ | Marcas oficiais das avaliações | Identificação, conforme NOTICE |

Ícones, marca e títulos próprios ficam em industry/brand/. Troque-os ao adaptar setor.
